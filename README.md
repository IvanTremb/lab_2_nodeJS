## Ход работы

В проект подключён Express.js. Приложение создаётся вызовом `express()` и прослушивает порт `3000`. Для обработки JSON в теле запросов используется middleware `express.json()`. Node.js обеспечивает выполнение JavaScript на сервере, а Express.js предоставляет удобные средства описания маршрутов и формирования HTTP-ответов.

Данные вынесены в файлы `models/bookModel.js` и `models/authorModel.js`. Исходные массивы содержат десять книг и десять авторов. Каждая книга имеет идентификатор, название, ссылку на автора, жанр и год издания. Для автора указаны идентификатор, имя и страна. Данные хранятся в памяти, поэтому изменения не сохраняются после перезапуска приложения.

Часть логики обработки запросов вынесена в контроллеры `bookController.js` и `authorController.js`. Разделение по принципам MVC выполнено частично: модели и контроллеры выделены, но маршруты и некоторые обработчики находятся непосредственно в `app.js`. Файлы в папке `routes` созданы, однако остаются пустыми; `express.Router()` не используется. Ответы API передаются в формате JSON, отдельные HTML-представления не предусмотрены.

В текущей версии зарегистрированы следующие маршруты:

| Метод | Маршрут | Реализация |
| --- | --- | --- |
| GET | `/books` | Возвращает массив всех книг |
| GET | `/books/:id` | Возвращает книгу по ID или статус 404 |
| POST | `/books` | Добавляет книгу и возвращает её со статусом 201 |
| PUT | `/books/:id` | Заменяет данные существующей книги или возвращает статус 404 |
| GET | `/authors` | Возвращает массив авторов |
| GET | `/authors/:id` | Зарегистрирован, но ошибочно вызывает поиск книги |
| GET | `/authors/:id/books` | Возвращает книги автора; при отсутствии автора — статус 404 |

Идентификаторы извлекаются из `req.params` и преобразуются в числа. Данные для добавления и обновления книги берутся из `req.body`. Ответы формируются с помощью `res.json()` либо `JSON.stringify()` и `res.end()`. При успешном чтении возвращается статус 200, при создании — 201. Для неизвестных маршрутов предусмотрен завершающий обработчик со статусом 404.

## Запуск приложения

Из папки `lab_2` необходимо установить зависимости и запустить сервер:

```bash
npm install
node app.js
```

Пример адреса для получения списка книг: `http://localhost:3000/books`.

## Замечания по текущей версии

При анализе исходного кода выявлены следующие расхождения с заданием:

- Пути маршрутов не содержат префикс `/api`. Вместо `PATCH` подключён `PUT`; маршрут `DELETE` отсутствует. Функция `patchBook()` не подключена к маршруту и не сохраняет изменения в исходном массиве.
- При добавлении книги обязательные поля не проверяются. Переданный `authorId` игнорируется и вычисляется автоматически; существование автора не проверяется. Ответ 400 для отсутствующих обязательных полей не предусмотрен.
- Получение автора по ID подключено к `getUniqBook()`. Функция `getUniqAuthor()` не экспортируется и содержит обращение к неопределённой переменной `book`.
- Фильтрация через `req.query`, поиск по части названия и маршрут статистики отсутствуют. Файл `middleware/logger.js` пуст, логирование запросов не подключено.
- Для неизвестного URL возвращается текст `somthing went wrong` вместо JSON с ошибкой `Route not found`. Ответ при отсутствии книги также отличается от заданного формата.
